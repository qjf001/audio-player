# 🎵 音乐播放器 (Music Player)

一款轻量级、纯净的 Android 本地音乐播放器，专为热爱音乐的你打造。

**无广告、无后台、无多余权限**，只为你提供最纯粹的听歌体验。

---

## ✨ 功能特色

- 🎧 **纯净无广告** — 专注音乐播放，没有任何广告干扰
- 🎶 **多格式支持** — MP3 / FLAC / WAV / AAC / M4A / OGG
- 📝 **歌词同步** — 歌词滚动显示，支持 `.lrc` 文件及内嵌歌词
- 📂 **智能分类** — 按文件夹自动归类，支持自定义标签管理
- ⏯️ **断点续播** — 上次听到哪里，打开继续听
- 🔀 **真随机播放** — 自研随机算法，不重复、不遗漏
- 🌐 **内置浏览器** — 在线发现更多音乐资源
- 🌍 **多语言** — 简体中文 / 繁體中文 / English
- ✏️ **编辑信息** — 修改歌曲艺术家、歌词等，可同步写回音频文件
- 🌙 **深色模式** — Material Design 风格，自动适配系统主题

## 🛠️ 编译构建

```bash

# 使用 Gradle 编译 Debug APK
gradle assembleDebug
```

APK 输出路径：`app/build/outputs/apk/debug/app-debug.apk`

## 📖 使用说明

1. **首次启动** — 自动扫描系统 `Music` 目录下的音频文件
2. **切换目录** — 点击右上角「设置」→「选择音乐目录」自定义扫描路径
3. **分类管理** — 在音乐目录下创建子文件夹，歌曲自动按文件夹名分类
4. **标签播放** — 为歌曲添加自定义标签，按标签随机播放
5. **发现音乐** — 底部导航栏切换到「发现」，内置网页浏览器可在线搜索音乐
